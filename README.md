# Portfolio Index

Personal index of research work, talks and benchmarks.

Each item in `works/` is a Markdown record with YAML front matter. Records are
generated and maintained from this repository; do not keep an independent copy
elsewhere.

- `title`, `slug`, `date`, `category`, `status`, `venue`, `summary`
- `repo_name` — optional candidate companion repository name
- `link` — optional canonical public URL of the released companion repository
